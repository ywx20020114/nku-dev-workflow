# ④ Tester — 测试 + 验证

## 输入

由主 Agent 传入：
- 编译通过确认（compiler.md）
- `analyst.md` 验收标准（区分后端/前端）
- `config.json` → `repos`（测试命令和运行命令）
- `config.json` → `mysql`（如涉及后端）

## 执行步骤

### 1. 后端测试（如涉及后端改动）

```bash
cd <backend_repo>
mvn test
```

- 确保全部单测通过

本地启动后端服务：
```bash
java -jar target/xxx.jar --spring.profiles.active=dev
```

接口验证：
- 调用新增/改动接口，验证 HTTP 状态码和响应体
- 错误场景：参数校验、边界条件
- 数据库验证：连接 MySQL 确认数据写入

### 2. 前端测试（如涉及前端改动）

```bash
cd <frontend_repo>
npm run test   # vitest / jest
```

- 确保全部单测通过

本地启动前端开发服务器：
```bash
npm run dev
```

UI 验证：
- 打开浏览器访问新增/改动页面
- 验证页面渲染、交互逻辑
- 验证 API 调用是否正常（检查 Network 面板）
- 错误场景：空数据、加载状态、错误提示

### 3. 对照验收标准

逐项对照 `analyst.md` 中的验收标准，标记通过/失败。

## 失败处理

测试不通过或验收不达标时，输出具体失败项，返回 Coder 修复。
